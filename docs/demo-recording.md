# 演示素材清单

录制使用虚构问题和可公开的资料。不要录到密钥、数据库密码、本地配置文件、个人信息或浏览器其他标签页。建议先准备两段有区分的历史会话，再开始正式录制。

## 必需：核心操作 GIF

- 文件名：`docs/images/workflow-demo.gif`。
- 时长：约 30—40 秒。保持正常播放速度，只剪去多余等待和重复点击。
- 顺序：总览停留 2 秒 → 新建会话 → 输入一个简短明确的问题并发送 → 展示逐字回复 → 输入关联追问 → 展示回复的一部分并点击停止 → 打开另一段历史会话并刷新，展示地址和内容保持一致。
- 问题示例：先问“用三点解释什么是 SSE，每点不超过二十字”，再追问“如果连接中断，前端应该怎么处理？”让提问过程出现在画面中，不要直接从已有答案开始。
- 重点是能看出流式交互和会话闭环，不必等长答案全部输出。若实际操作超过 40 秒，保留完整录屏后再剪预览，不要靠加速掩盖等待。

## 建议：阅读跟随 GIF

- 文件名：`docs/images/scroll-follow.gif`。
- 时长：约 12—18 秒。
- 先准备足够长的历史消息；让模型生成一段较长回答 → 底部跟随 2—3 秒 → 向上滚动并停留 3—4 秒，显示内容仍在生成但阅读位置不被拉走 → 点击“回到最新消息” → 展示恢复跟随。
- 不要只录鼠标移动，要让文字增长、暂停跟随和恢复跟随能同时被看懂。

## 录制与导出

- 优先录制 MP4 原文件，后续再导出 GIF，便于保留清晰的完整版本。
- 录制分辨率建议 1440 × 900 或 1600 × 900，浏览器缩放保持文字清楚。
- GIF 可尝试宽 1000—1200 像素、8—12 帧/秒；减少帧率不等于加快播放，必须保留原时长。
- 每张 GIF 目标控制在 3—5 MB 左右；若超出，先缩尺寸或减少重复片段，不牺牲文字可读性，也不保证任何网络下的加载时间。
- 可另留 60—90 秒完整 MP4，覆盖知识库上传、引用和调用记录。README 用 GIF 预览、一个完整视频入口即可，不重复放多个下载链接。
